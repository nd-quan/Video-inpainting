Temporal Gradient Guidance after Shared Noise

Hướng dẫn triển khai cho BrushNet/DDIM, không thay đổi trực tiếp bất kỳ file Python nào.

Mục lục 1. Phạm vi 2. Trạng thái code 3. Công thức 4. Luồng xử lý 5. File cần thay đổi 6. Optical flow 7. Temporal loss 8. DDIM guidance 9. Test theo clip 10. Bộ nhớ 11. Kiểm thử 12. Lỗi dễ gặp

1. Phạm vi của phiên bản đầu tiên

Mục tiêu

Giữ nguyên shared-noise initialization hiện tại, sau đó thêm temporal guidance chỉ trên vùng BG ổn định trong quá trình reverse DDIM sampling.

  • BG/ROI mask có thể thay đổi theo frame.
  • Một object không thay đổi semantic membership giữa ROI và BG.
  • Chỉ những pixel là BG ở cả hai frame sau alignment mới tham gia temporal loss.
  • Optical flow và visibility mask được tính một lần từ degraded input.
  • Không backpropagate qua optical-flow model.
  • Không thay đổi shared noise bằng temporal gradient.
  • Chưa kết hợp PGD residual trong ablation đầu tiên.
Shared noise tạo prior chung ở bước khởi tạo. Temporal guidance là ràng buộc bổ sung trong từng denoising step. Hai cơ chế này bổ trợ nhau nhưng không nên gộp thành một biến cập nhật.

3. Công thức sử dụng

3.1 Backward warping

Với grid_sample, nên dùng backward flow current-to-previous, ký hiệu Fi→i-1.

W(Xi-1, Fi→i-1)(p) = Xi-1(p + Fi→i-1(p))

3.2 Stable-BG mask

SiBG = Bi ⊙ W(Bi-1, Fi→i-1) ⊙ Vi
  • Bi = 1 tại BG hiện tại, 0 tại ROI.
  • W(Bi-1, F) là previous BG mask đã được align về frame hiện tại.
  • Vi = 1 ở vùng không occlusion, trong biên và flow đáng tin cậy.
  • SiBG chỉ giữ vùng BG có correspondence hợp lệ.

3.3 Robust temporal loss

LBG-temp(t) = Σi=2N [Σp,c SiBG(p) ρ(x̂0,ti(p,c) - W(x̂0,ti-1, Fi→i-1)(p,c))] / [3ΣpSiBG(p) + ε]

Charbonnier penalty được dùng thay cho absolute value cứng:

ρ(d) = √(d² + εchar²)

3.4 Gradient guidance

gt = ∇ẑ0,t LBG-temp(D(ẑ0,t))
z̃0,t = ẑ0,t - ηt normalize(gt)

DDIM sau đó dùng z̃0,t thay cho ẑ0,t để tính zt-1. Temporal loss differentiable nên không cần finite-difference CGE.

4. Luồng xử lý đề xuất

Degraded clip [N, 3, H, W] | +----> RAFT / SEA-RAFT (chạy một lần, no_grad) | | | +----> forward flow | +----> backward flow | +----> visibility/confidence mask | +----> ROI masks ----> BG masks ----> stable-BG pair masks | +----> BrushNet shared-noise initialization | v DDIM denoising step t | v predicted clean latent z0 | v VAE decode predicted x0 | v stable-BG temporal loss | v gradient with respect to z0 | v guided z0 ----> DDIM z(t-1)

6. Precompute optical flow và visibility

6.1 Load RAFT một lần

from torchvision.models.optical_flow import (
    raft_large,
    Raft_Large_Weights,
)

flow_weights = Raft_Large_Weights.DEFAULT
flow_transform = flow_weights.transforms()
flow_model = raft_large(
    weights=flow_weights,
    progress=False,
).to(device).eval()

for parameter in flow_model.parameters():
    parameter.requires_grad_(False)

6.2 Tính cả hai hướng cho clip

frames phải là full degraded RGB frames, không phải ảnh đã tách FG/BG. Shape: [N, 3, H, W], range [0, 1]. 

@torch.no_grad()
def estimate_bidirectional_flow(frames, flow_model, flow_transform):
    previous = frames[:-1]
    current = frames[1:]

    previous_input, current_input = flow_transform(previous, current)

    flow_forward = flow_model(
        previous_input,
        current_input,
    )[-1]  # previous -> current

    flow_backward = flow_model(
        current_input,
        previous_input,
    )[-1]  # current -> previous

    return flow_forward, flow_backward
Tensor dùng cho grid_sample(previous, flow) là flow_backward. Forward flow chủ yếu dùng để kiểm tra cycle consistency.

6.3 Backward warp helper

def backward_warp(source, flow):
    batch, _, height, width = source.shape

    y, x = torch.meshgrid(
        torch.arange(height, device=source.device),
        torch.arange(width, device=source.device),
        indexing="ij",
    )

    sample_x = x.float()[None] + flow[:, 0]
    sample_y = y.float()[None] + flow[:, 1]

    in_bounds = (
        (sample_x >= 0)
        & (sample_x <= width - 1)
        & (sample_y >= 0)
        & (sample_y <= height - 1)
    ).unsqueeze(1)

    grid_x = 2.0 * sample_x / max(width - 1, 1) - 1.0
    grid_y = 2.0 * sample_y / max(height - 1, 1) - 1.0
    grid = torch.stack([grid_x, grid_y], dim=-1)

    warped = torch.nn.functional.grid_sample(
        source,
        grid,
        mode="bilinear",
        padding_mode="zeros",
        align_corners=True,
    )

    return warped, in_bounds.to(source.dtype)

6.4 Forward-backward visibility mask

def forward_backward_visibility(
    flow_forward,
    flow_backward,
    alpha=0.01,
    beta=0.5,
):
    # Sample previous->current flow at the previous coordinate
    # corresponding to each current-frame pixel.
    warped_forward, in_bounds = backward_warp(
        flow_forward,
        flow_backward,
    )

    cycle = flow_backward + warped_forward
    cycle_error = cycle.square().sum(dim=1, keepdim=True)

    flow_magnitude = (
        flow_backward.square().sum(dim=1, keepdim=True)
        + warped_forward.square().sum(dim=1, keepdim=True)
    )

    consistent = cycle_error <= alpha * flow_magnitude + beta
    return consistent.to(flow_backward.dtype) * in_bounds

6.5 Stable-BG mask

Nếu mask input là ROI=1, phải đổi thành bg_masks = 1 - roi_masks. 

warped_previous_bg, bg_in_bounds = backward_warp(
    bg_masks[:-1],
    flow_backward,
)

# Có thể giữ soft mask hoặc threshold để tránh boundary interpolation.
warped_previous_bg = (
    warped_previous_bg > 0.5
).to(bg_masks.dtype)

stable_bg = (
    bg_masks[1:]
    * warped_previous_bg
    * visibility
    * bg_in_bounds
)

7. Hàm temporal loss

def bg_temporal_loss(
    predicted_images,
    flow_backward,
    stable_bg,
    charbonnier_eps=1e-3,
):
    # predicted_images: [N, 3, H, W]
    # flow_backward:    [N-1, 2, H, W]
    # stable_bg:        [N-1, 1, H, W]

    warped_previous, in_bounds = backward_warp(
        predicted_images[:-1],
        flow_backward,
    )

    pair_mask = stable_bg * in_bounds
    difference = predicted_images[1:] - warped_previous

    robust_error = torch.sqrt(
        difference.float().square() + charbonnier_eps**2
    )

    numerator = (robust_error * pair_mask.float()).sum()
    denominator = (
        pair_mask.float().sum() * predicted_images.shape[1]
    ).clamp_min(1.0)

    return numerator / denominator

Joint hay causal gradient?

Kiểu Code Đặc điểm
Joint clip predicted_images[:-1] Gradient đi vào cả previous và current frame; đối xứng nhưng tốn memory hơn.
Causal predicted_images[:-1].detach() Chỉ current frame thay đổi; dễ kiểm soát nhưng có thể tích lũy drift.

Thí nghiệm đầu tiên nên dùng joint clip vì shared noise cũng đang được áp dụng đồng thời cho clip. Nếu OOM, chuyển sang causal pair guidance.

8.2 Vị trí chính xác trong step()

Temporal block nên chạy sau khi DDIM tính và clip pred_original_sample, nhưng trước: 

pred_sample_direction = ...
prev_sample = sqrt(alpha_prev) * pred_original_sample + ...

Không nên đợi đến sau khi có prev_sample rồi cộng temporal gradient trực tiếp, vì gradient được tính đối với predicted clean latent, không phải đối với noisy prev_sample.

8.3 Predicted-x0 temporal guidance block

should_run_temporal = (
    getattr(self, "temporal_guidance_enabled", False)
    and pred_original_sample.shape[0] > 1
    and self.temporal_start_step
        <= self.temporal_step_count
        < self.temporal_end_step
    and self.temporal_step_count
        % self.temporal_every_n_steps == 0
)

if should_run_temporal:
    with torch.enable_grad():
        z0 = pred_original_sample.detach().requires_grad_(True)

        decoded_chunks = []
        for start in range(0, z0.shape[0], self.decode_chunk_size):
            z0_chunk = z0[start:start + self.decode_chunk_size]
            decoded_chunks.append(
                self.decoder(
                    z0_chunk / self.vae_scaling_factor
                ).sample
            )

        predicted_images = torch.cat(decoded_chunks, dim=0)

        temporal_loss = bg_temporal_loss(
            predicted_images=predicted_images,
            flow_backward=self.temporal_flow_backward,
            stable_bg=self.temporal_stable_bg,
        )

        temporal_grad = torch.autograd.grad(
            temporal_loss,
            z0,
            retain_graph=False,
        )[0]

    # Spatially restrict the latent update to BG.
    bg_mask_latent = torch.nn.functional.interpolate(
        self.temporal_bg_masks.to(
            device=z0.device,
            dtype=z0.dtype,
        ),
        size=z0.shape[-2:],
        mode="nearest",
    )
    temporal_grad = temporal_grad * bg_mask_latent

    # Per-frame normalization.
    grad_norm = torch.linalg.vector_norm(
        temporal_grad.float().reshape(temporal_grad.shape[0], -1),
        ord=2,
        dim=1,
    ).clamp_min(1e-8)

    normalized_grad = temporal_grad / grad_norm.view(-1, 1, 1, 1)

    pred_original_sample = (
        pred_original_sample
        - self.temporal_guidance_scale * normalized_grad
    )

    self.last_temporal_loss = float(
        temporal_loss.detach().cpu()
    )
    self.last_temporal_grad_norm = float(
        grad_norm.mean().detach().cpu()
    )

self.temporal_step_count += 1
Pipeline hiện được trang trí bởi inference/no-grad context. Block trên bắt buộc phải có torch.enable_grad() và z0.requires_grad_(True). VAE parameters có thể đặt requires_grad_(False); gradient theo input latent vẫn hoạt động.

8.4 Không double guidance

Nếu dùng predicted-x0 temporal guidance, không được tiếp tục cộng cùng temporal gradient bằng prev_sample = prev_sample + grad. Một temporal gradient chỉ được áp dụng một lần.

10. Kiểm soát VRAM và thời gian

  1. Bắt đầu bằng clip_size=4, không phải 8 hoặc 32.
  2. Dùng decode_chunk_size=1 để VAE decode từng frame nhưng vẫn giữ graph.
  3. Flow chạy trước sampling và tensor output được detach.
  4. RAFT có thể chuyển về CPU sau khi precompute flow nếu thiếu VRAM.
  5. Chỉ chạy temporal guidance trong một window, ví dụ step [15,40).
  6. Có thể dùng temporal_every_n_steps=2 để giảm một nửa số lần VAE decode.
  7. Không bật CGE/VVC trong ablation temporal đầu tiên.
Decode theo chunk giảm activation peak, nhưng temporal loss vẫn được tính trên tensor ảnh đã concatenate nên gradient giữa các frame vẫn tồn tại.

11.4 Tiêu chí đánh giá

  • BG warping error giảm so với shared-noise-only.
  • tLPIPS hoặc temporal LPIPS giảm.
  • Restoration PSNR/SSIM/LPIPS không giảm đáng kể.
  • Không xuất hiện ghosting tại ROI boundary.
  • Stable-BG ratio không quá nhỏ; nếu gần 0 thì flow/mask convention đang sai.
