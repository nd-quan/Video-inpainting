1. Objective and design constraints

The original BrushNet pipeline processes video frames as an image batch. BrushNet supplies spatial conditioning residuals to the diffusion U-Net, but those residuals do not explicitly communicate motion from the previous frame. The motion adapter introduces adjacent-frame motion while preserving all pretrained components.

Primary objective

Align the previous frame's multi-scale BrushNet features with the current frame using refined backward optical flow, then learn a small residual correction for the U-Net.

Constraints

  • Do not change BrushNet or U-Net architecture.
  • Keep all pretrained models frozen.
  • Preserve the image-only baseline at initialization.
  • Support variable clip length and batch size.
  • Handle classifier-free guidance without mixing branches.
Trainable scope: only the flow-guided motion adapter is optimized. VAE, CLIP text encoder, CLIP image encoder, IP-Adapter, foreground/background fusion, BrushNet, and diffusion U-Net remain frozen.

3. Refined-flow representation

For two adjacent frames, the implementation stores both directions:

  • refined_f: forward flow, frame t−1 to frame t.
  • refined_b: backward flow, frame t to frame t−1.
  • motion_confidence: full-frame forward/backward consistency and in-bounds confidence.
  • stable_bg: confidence restricted to background pixels stable in both aligned frames.
The adapter uses backward flow. For every target position in the current frame, backward flow identifies which position to sample from the previous-frame feature map. This is directly compatible with differentiable backward warping through grid_sample.
F̂t→t−1(x) tells the sampler to read the previous feature at x + F̂t→t−1(x).

Confidence definitions

With forward flow F̂t−1→t and backward flow F̂t→t−1, the cycle error at a current-frame position is:

eFB(x) = ‖F̂t→t−1(x) + W(F̂t−1→t, F̂t→t−1)(x)‖²
Cmotion(x) = 𝟙[eFB(x) ≤ αm(x) + β] · 𝟙[x is in bounds],   α = 0.01, β = 0.5

motion_confidence gates adapter corrections over the entire image, including ROI. stable_bg additionally intersects the current background with the backward-warped previous background and is reserved for temporal reconstruction loss.

4. Multi-scale feature warping

BrushNet generates residual maps at several resolutions. The original flow is stored at 432 × 240 and must be resized to each feature resolution Hl × Wl. Spatial interpolation alone is not enough: displacement values must also be rescaled.

F̂lx = Resize(F̂x) · Wl/W,    F̂ly = Resize(F̂y) · Hl/H

The previous-frame residual is aligned to current coordinates as:

R̄lt−1→t(x) = W(Rlt−1, F̂lt→t−1)(x) = Rlt−1(x + F̂lt→t−1(x))

The implementation uses bilinear torch.nn.functional.grid_sample, zero padding, and align_corners=True. Confidence is resized independently to the same feature resolution and clamped to [0, 1].

BrushNet already exposes three residual collections consumed by the modified diffusion U-Net:

Frame zero has no previous frame and is never corrected. The runtime scalar motion_adapter_scale controls injection strength without modifying the saved adapter.

Up-path injection is intentionally disabled in the first experiment. Up residuals have high spatial resolution, increase memory consumption, and can directly perturb fine textures. Down + mid provides motion at semantic and structural scales before evaluating higher-risk up-path injection as an ablation.

Classifier-free guidance at inference

The deployed pipeline concatenates unconditional and conditional branches as: 

[all unconditional frames, all conditional frames]
shape = [2 × B × T, C, H, W]

The adapter reshapes residuals to [CFG_branch, B, T, C, H, W] before temporal pairing. Therefore frame t−1 and frame t are paired only inside the same sample and the same CFG branch. Unconditional and conditional features can never be accidentally warped into one another.

8. Training architecture

  1. Load a sequential VCM clip, ROI masks, refined flows, and confidence maps.
  2. Encode clean ground-truth frames into target VAE latents.
  3. Encode VCM-decoded frames and concatenate the latent background mask, producing the deployed five-channel BrushNet condition.
  4. Construct foreground/background images and obtain the same four frozen IP-Adapter tokens used at inference.
  5. Sample one diffusion timestep per clip and repeat it across all T frames.
  6. Generate independent ROI noise and correlated/shared background noise.
  7. Run frozen BrushNet under no_grad to obtain residual features.
  8. Run the trainable motion adapter on down and mid residuals.
  9. Run the frozen-parameter U-Net with autograd enabled.
  10. Backpropagate diffusion and temporal losses through U-Net operations into the motion adapter.
Important distinction: U-Net parameters are frozen, but the U-Net forward pass is not detached. Autograd must retain the path from U-Net output to injected residuals; otherwise the motion adapter receives no gradient from the noise-prediction loss.

Shared timestep and shared background noise

Every frame in the same clip uses one common diffusion timestep τ. This ensures that temporally paired features operate at the same noise level. Background noise can be correlated across frames:

εBG,t = √(1−ρ) εind,t + √ρ εshared,    ρ = 1.0 by default

9. Training objective

L = λεLnoise + λT√ᾱτLtemporal + λRLresidual
TermDefault weightDefinition
Noise prediction λε = 1.0 MSE between predicted and target diffusion noise (or velocity when configured).
Temporal warp λT = 0.05 Charbonnier difference between current predicted-clean latent and the backward-warped previous predicted-clean latent, gated by stable background.
Residual regularization λR = 10−4 Mean squared magnitude of the adapter's changes to BrushNet residuals.
Ltemporal = Σ CBG,t ρ( ẑ0t − W(ẑ0t−1, F̂t→t−1)) / (Σ CBG,t + ε)

Temporal loss is computed in predicted-clean latent space rather than decoded RGB space. This avoids backpropagating through the VAE decoder and substantially reduces VRAM. The √ᾱτ weighting prevents high-noise timesteps from dominating after predicted-clean conversion.

10. Two-GPU distributed training

The trainer supports PyTorch Distributed Data Parallel. Each process contains a frozen copy of the full pipeline, but DDP wraps only the small trainable motion adapter.

Global batch = 2 GPUs × 1 clip/GPU × 2 accumulation steps = 4 clips
  • DistributedSampler gives each rank different clips.
  • no_sync() avoids unnecessary gradient communication during intermediate accumulation steps.
  • Adapter gradients are synchronized at the optimizer boundary.
  • Validation statistics are summed and averaged across ranks.
  • Only rank 0 writes logs, TensorBoard events, and checkpoints.

12. Initialization and safety properties

Exact baseline at initialization

Every output projection is initialized with zero weights and zero bias. Therefore ΔR = 0 for every port before training, regardless of flow, confidence, or random internal weights.

No correction for frame zero

Corrections are allocated only for frame indices 1…T−1. The first frame remains identical to the original BrushNet output.

Confidence gating

Inconsistent or out-of-bounds motion is suppressed before injection, limiting the influence of unreliable flow.

Residual rather than replacement

The adapter adds a scaled correction. It never discards the original pretrained BrushNet residual.

Implemented unit tests

  • Flow displacement is scaled correctly during resize.
  • Backward warp uses the current-to-previous direction.
  • Zero initialization exactly preserves the baseline under CFG.
  • The first frame is never corrected.
  • Zero flow produces stable confidence for identical backgrounds.
  • Identical frames produce near-zero temporal loss.
  • Gradients reach the adapter through a frozen U-Net.

13. Limitations and planned ablations

  • V1 uses only first-order adjacent-frame propagation; it does not maintain a recurrent hidden state across the entire video.
  • It uses bilinear warping rather than deformable alignment. This is smaller and safer but may be weaker near occlusion boundaries.
  • Up-path residual adaptation is disabled until down + mid behavior is validated.
  • Flow refinement and motion-adapter training are separate stages; gradients do not update the flow model.
  • Each DDP rank replicates the frozen diffusion stack, so DDP improves throughput but does not reduce per-GPU model memory.

Recommended ablations

  1. Image-only baseline versus motion adapter.
  2. Raw RAFT flow versus fine-tuned refined flow.
  3. No confidence gate versus full-frame motion confidence.
  4. Down-only versus down + mid versus down + mid + up.
  5. Motion adapter only versus temporal scheduler guidance only versus both.
  6. Motion scale values 0.25, 0.5, 0.75, and 1.0.
